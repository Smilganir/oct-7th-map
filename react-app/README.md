# Oct-7th-Map (React rebuild of the Tableau map)
Stack: React 18, TypeScript, Vite, MapLibre. Live at https://smilganir.github.io/oct-7th-map/ (repo root = the built output on `main`).
Source of truth for the data: Nir's frozen Tableau Public workbook Oct-7th_Otef (rev 6.5).

## Build
    cd react-app && npm ci
    VITE_ARC_KEY=<Esri key> VITE_MAPBOX_TOKEN=<Mapbox pk token> npx vite build
Both keys are public, referrer-restricted client keys, read at build time only (not in source). Without VITE_MAPBOX_TOKEN the Mapbox step is skipped.
Basemap chain: Esri imagery (grayscale) -> Nir's Mapbox style (smilganir) -> OSM (grayscale); each step after 4 tile errors.
Root build post-step (done on the built index.html): remove the noindex meta, set title "Oct-7th-Map", add the GA tag G-8Z0X9ZJFH9.
Deploy = copy dist/* into the repo root of `main` (keep archive/ and docs/).

## Data
- `src/data.json`: `scripts/prepare_assets.sh` + `scripts/build_data.py` (from the Tableau Public workbook).
- `public/detail.json` (settlement victim lists, photo URLs) and `public/he.json` (Hebrew names): NOT generated by a script in this repo. Built earlier from Nir's Drive sheet "oct7database" (tab Data); the generator is not saved here.
- `public/photos/`: `scripts/download_photos.py` (self-hosted copies; the code falls back to the original URL if a file is missing). The deployed copy is `photos/` in the repo root on main.
